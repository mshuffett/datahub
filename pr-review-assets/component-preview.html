State machine:
  focused=false                      → browser hidden,  dropdown hidden
  focused=true  + searchText=""      → browser VISIBLE, dropdown hidden
  focused=true  + searchText.len>0   → browser hidden,  dropdown VISIBLE
  deselect tag                       → removes URN from ResourceFilter.criteria[GLOSSARY]
  select (dropdown or browser)       → appends URN+entity to ResourceFilter.criteria[GLOSSARY]
